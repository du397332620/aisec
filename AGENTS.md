## Agent skills

### Issue tracker

Tasks are tracked in local Markdown files under `.scratch/<feature>/` and are not published to GitHub. Local-only details live in `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five triage states: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. Use `completed` only after acceptance evidence exists. Local-only details live in `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context layout with `CONTEXT.md` at the repository root and architectural decisions under `docs/adr/`. Missing domain files are not blockers. Local-only details live in `docs/agents/domain.md`.
